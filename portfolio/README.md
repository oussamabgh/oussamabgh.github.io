# Oussama Boughanem - Developer Portfolio

Static portfolio site built from project analysis data.

## Structure
- `index.html` - Main portfolio page (Hero, Skills, Projects)
- `case-study.html` - Individual project case studies
- `data/` - Portfolio data files (generated from analysis)
  - `*.md` - Project case studies
  - `skills.json` - Skills grouped by category with evidence counts
- `style.css` - Styles with light/dark mode support
- `app.js`, `case-study.js` - JavaScript for dynamic content

## Development
Open `index.html` in a browser or serve with a local server.

## Deployment
Deployed via GitHub Pages to https://oussamabgh.github.io
