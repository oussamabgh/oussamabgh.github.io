# clubPlay_final

**Pitch:** Social/club app with real-time voice rooms, chat, and social features
**Problem:** Enables users to join voice rooms, interact socially, and manage profiles with real-time updates

**Tech Stack:** Flutter/Dart, Firebase, Agora RTC, BLoC, Riverpod, Cloud Firestore
**Architecture:** Modular code organization with separation of concerns (services/controllers/blocs as present).

## Technical Highlights
1. lib/screens/VoiceRooms/VoiceRooms.dart:1754 - Voice rooms UI and real-time audio room management
2. lib/screens/Profile/My_profile.dart:1537 - User profile management and social features
3. lib/screens/Church/wedding_room.dart:1126 - Church/event room functionality
4. lib/screens/Ranking/Components/Main_rank.dart:1067 - Ranking and leaderboard system
5. lib/bloc/ and lib/services/ - State management and business logic (BLoC pattern)

## Challenges Solved
- Implemented robust data processing and real-time updates
- Structured maintainable, scalable codebase

## Measurable Results
- Real-time voice/audio rooms via Agora RTC integration
- Firebase backend (Auth, Firestore, Storage, Realtime DB) for scalable data sync
