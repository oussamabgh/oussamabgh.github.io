# solana_project

**Pitch:** Solana blockchain analysis and forensics toolkit
**Problem:** Solves domain-specific engineering/build challenges in this project space.

**Tech Stack:** Python, Solana, Data Analysis, Pandas/CSV Processing
**Architecture:** Modular code organization with separation of concerns (services/controllers/blocs as present).

## Technical Highlights
1. launch_detector.py - Solana token launch detection logic
2. reading_transaction.py - Transaction parsing and analysis
3. profiler.py - Performance profiling and analytics
4. wallet_forensics*.csv - Wallet forensics data outputs
5. rug_dna_by_token.csv, rug_duration_report.csv - Analysis reports

- Implemented robust data processing and real-time updates
