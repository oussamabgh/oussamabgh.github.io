# video_pipeline

**Pitch:** Automated AI video generation pipeline with rendering and assembly
**Problem:** Solves domain-specific engineering/build challenges in this project space.

**Tech Stack:** Python, FFmpeg, Video Processing, Automation, JSON
**Architecture:** Modular code organization with separation of concerns (services/controllers/blocs as present).

## Technical Highlights
1. height_pipeline.py - Main video generation pipeline orchestration
2. height_video_assembler.py - Video assembly and rendering logic
3. height_narration_agent.py - AI narration generation
4. height_script_agent.py, height_storyboard_agent.py - Script and storyboard generation
5. main_pipeline_mac.py - macOS-specific pipeline entry point

## Challenges Solved
- Implemented robust data processing and real-time updates
- Structured maintainable, scalable codebase

## Measurable Results
- Automated end-to-end video generation pipeline (script → storyboard → narration → rendering → assembly)

## Skills Demonstrated
- Python, Socket.IO
